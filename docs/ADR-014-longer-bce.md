# ADR-014: separate fixed-duration exploratory run
Reuse the existing trainer contract without modifying frozen sources. A new run extends the v5 full BCE schedule to16epochs and selects epoch16 for best.pt export (last.pt remains an every-epoch recovery checkpoint). Existing training lifecycle/lock/checkpoint semantics remain unchanged. The bounded launch wrapper owns only launch/exit evidence; it cannot promote failed runs or clear locks. v13 terminal state remains intact. User explicitly accepts trial exports with disclosed quality regression. Full plan: science-superpowers/plans/2026-10-30-v14-longer-bce.md. No API or persisted trainer schema changes.
