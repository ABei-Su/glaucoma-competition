# ADR-002: Isolated supervised continuation and bounded fusion
Status: accepted under user's autonomous optimization instruction.

Preserve baseline weights, data cache and submissions. Create a new resolution cache directly from raw train/valid images and bind it to the original verified image hashes. New runs can initialize from the baseline's official-data supervised checkpoint; this is supervised continuation, not external medical pretraining. Seed, learning rate and positive-class weight are explicit and resume-validated.

Inference supports a schema_version=1 JSON bundle of one or two ResNet18 checkpoints. Each has a fixed boolean horizontal-flip TTA setting. Average probabilities equally; no trainable inference parameter or test adaptation. Legacy single .pt inference remains supported. JSON paths are relative to the bundle and refer only to trusted locally produced files. Both predict and cost use the same Predictor.

Compare models using official validation only. The chosen actual single-image path is re-evaluated on all validation images. Local timing uses 5 validation warmups then 100 other validation images in 3 full serial rounds and includes file input/output. <=80ms is an engineering margin on local RTX4060, not evidence of official T4 compliance. Model selection still requires final T4 verification when hardware is available.

Before final comparison, inference sigmoid is computed in FP32 from FP16 forward logits to avoid unnecessary probability ties. Candidate comparison and final Predictor share this conversion; all baseline/optimized same-path metrics are recomputed. Training/checkpoint selection remains the recorded original procedure.

Final candidate comparison uses batch=1 and FP32 TTA averaging exactly as Predictor, from lossless caches verified pixel-equal to deterministic raw preprocessing. The selected winner and baseline are additionally recomputed from raw images. This avoids selecting across a batched-versus-single numerical mismatch.

Profiling validation images showed repeated original-image preprocessing dominated latency (two GPU forwards ~6.6ms vs duplicated preprocessing ~100ms). Share per-image border crop between resolutions and avoid redundant RGB/EXIF copies when no conversion is required. Exact-pixel regression tests across RGB/L/RGBA and all EXIF orientations passed. Final validation recomputation and timing follow; no model parameters or test-driven preprocessing changes.
