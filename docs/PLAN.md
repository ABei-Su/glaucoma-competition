# 青光眼参赛项目：设计与执行计划

用户授权：自主解压、实施和解决中间问题；最终由用户提交。2026-10-23。

## 目标与边界
以每张图像为单位预测阳性概率。只用官方 train 训练，官方 valid 选择 checkpoint，以 AUROC 优先、同分以 average precision 辅助排序；另报梯形积分 AUPRC，避免两种实现混淆。不将验证集并入训练。测试集不用于画像、调参、模型选择或任何统计拟合。此为预测建模与探索性调优，不作显著性或临床有效性声明。

## 设计
原始 zip 保留；安全解压到 data/raw。派生训练/验证缓存独立保存。先使用 torchvision ImageNet 通用视觉权重，固定确定性输入预处理，训练时增强。优先小型单模型，避免 8GB 本机显存和赛事 100ms/500MB 限制；架构具体选择以环境可用性和训练吞吐测试为依据。预训练来源、许可证、SHA256 一并保存。推理无下载、无梯度、eval 模式。predict.py 与 cost.py 共享同一推理对象。

## 生命周期与恢复
准备→训练→验证→保存→下一轮/完成。验证失败不推进轮次；先原子保存 last 和 best，外部状态为已提交 checkpoint；中断从 last 恢复，保存优化器、调度、随机状态。一次仅一个训练任务操作同一 run。输出替换用临时文件与原子 rename，源数据不修改。所有下载有超时和有限重试。测试结果仅在模型已冻结后生成。

本机 RTX4060 8GB，不是官方 T4；本机耗时不能作为 T4 达标证明。比赛指定 Python3.12/PyTorch2.10/torchvision0.25，当前可用环境需实测并声明。模型许可需核对权重来源与代码许可，不能将代码许可自动视为所有数据权利。验证样本有限且可能存在患者相关性；若缺少患者 ID，只能声明限制，不能假造患者级隔离。样本量固定，不作功效检验或医疗结论。
