# ADR-001: Small image-only supervised baseline
Status: accepted under user's autonomous implementation authorization, 2026-10-23.

Choose ResNet-18 ImageNet-1K, 224 input and official held-out validation. The available GPU is 8GB and official inference budget is 100ms/500MB. Larger backbones, multi-model ensembles and higher resolution may help but require measured evidence, so they are deferred. Metadata fusion is deferred to avoid relying on age fields at inference before dataset contracts are established.

Each image preserves aspect ratio after per-image border removal. This can lose small dark peripheral regions; the selected transform must be evaluated only on validation. There is no test-adaptive preprocessing. Source crop, threshold and size are fixed before test inference. Probability output is binary sigmoid, label uses >=0.5. Official AP integration method is unspecified, so log both average precision and trapezoidal PR area.

Model is saved as state_dict plus primitive metadata. Official runtime validation is a separate requirement from successful local training. Rollback selects a previously validated checkpoint without changing raw files. No persisted schema migration is required for initial v0.1.0; future checkpoint metadata changes need an explicit version.
