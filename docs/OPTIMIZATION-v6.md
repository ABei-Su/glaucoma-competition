# 第六版固定双架构等权组合计划

用户要求继续优化，最终平台目标99.3。此计划在计算第六版组合指标前写定，属于探索性验证，不是新的独立验证或临床证据。

现有第五版单模型原图验证AUROC略低于固定第三版，AP略高。没有发现代码故障，主因未知。本次只检验一个新问题：两种架构的固定等权概率平均，能否在官方valid上优于固定第三版，并满足100ms和500MB限制。保留第五版未升级结论，不更改其参数或重选轮次。

唯一候选：runs/v3_r50_384_w1/best.pt（固定第三版、水平翻转true）+runs/v5_full/best.pt（内部选定ConvNeXt epoch8、水平翻转true），概率Python浮点等权1:1。阈值0.5。无权重拟合、无阈值搜索、无新增种子或其他融合候选；若速度或精度不达标，本计划停止，不临时追加方案。

初始计算仅用v5流程已保存、逐张原图推理的validation_predictions.csv和baseline_single_image_validation.csv，严格核对5849个名字/顺序、标签来源与各模型配置，并记录文件与权重SHA。初步组合概率可能受CSV10位有效数字舍入影响，因此不能取代最后原图复核。

唯一组合按最终Predictor再跑完整valid，并同路径复算第三版；严格AUROC提高（完全相同时AP提高）才生成测试CSV。用官方valid的100张图、5预热、3轮batch1端到端本机测速，<=100ms；官方T4仍待另测。只有冻结组合完成选择后，才读取测试图片生成最终CSV；不使用测试统计或平台分数拟合。

两个完整模型都使用官方train训练过，不得用v5内部holdout评估这对最终权重并声称独立无泄漏验证。此前内部结果仅证明新架构可学习，不能作为第六版组合的独立复现。官方valid已反复使用，区间仅描述，仍有选型偏差和未知患者聚类限制。

若达标，材料只包含两个推理权重、必要代码、两种公开ImageNet权重和第三版R50阶段1初始化及报告；不重复附已经作为最终成员的第三版阶段2权重。严格检查运行资产和最终ZIP均<=500MB。若ZIP超限，先去掉重复且可由已有权重重用的文件，不能偷偷漏掉实际初始化来源或伪报体积。
