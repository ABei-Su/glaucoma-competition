# ADR-009: isolated image + Age model contract

Accepted2026-10-27 under continued autonomous optimization. Extend input capability in new modules instead of changing old frozen code and checkpoints. Data/image preprocessing and original image backbones remain imported dependencies.

New architecture convnext_tiny_age/checkpoint schema2 contains image and zero-initialized age head parameters, validated age_stats, underlying public-source hash, data and split fingerprints, selected epoch and training scope. Resume must match all recipe fields, transform statistics and raw/cache fingerprints; no fallback to a different age transform. An image-only checkpoint cannot be silently loaded as an Age model or vice versa.

Age is a per-image organizer-provided input. Fit mean/std on the actual training partition only; encode missing/invalid values deterministically, retain all images and count quality issues. At inference a schema2bundle names an immutable metadata source. Lookup keys are case-folded basenames, duplicates/collisions rejected, metadata contains only Image_name/Age for inference. No per-test fitting, imputation statistics, patient-ID model feature or label column is permitted. Unknown filenames use fixed training-mean/missing-indicator encoding, a documented supported fallback. Use the same age vector for both TTA views, sum logits in FP32 and average probabilities with fixed model weights.

clinical_predict owns the new reader and shares it with timing and prediction, delegating compatible image-only backbone construction to the existing model module. New code must reproduce zero-age-head image behavior and retain legacy original Predictor unchanged. Stage appropriate code plus model/config/metadata bindings if a package is later needed. A metadata source must be explicit and hash-bound; output reproducibility includes it.

Training lifecycle reuses existing explicit Lifecycle and atomic checkpoint helpers. Coordinator uses bounded ready/verifying/resource_probe/internal_training/internal_comparison/full_training/complete or not_promoted/failed transitions, central audit writes and exclusive lock. Started jobs are unique; duplicated/out-of-order completion is rejected via frozen run identities. No automatic retry, stale-lock deletion or silent restart of terminal state. Background processes continue independently of the chat; unexpected failures require a later active turn to investigate. No publication or upload is performed.

Rollback: cease v10, preserve all v6/v8/v9 outputs; no migration of old readers or persisted models. Tests must cover parsing/schema/shape boundaries, missing metadata, duplicate lookup, pure-image equivalence, synthetic learnability, deterministic resume and source mismatches. OfficialT4 verification remains outstanding.
