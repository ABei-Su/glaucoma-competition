# ADR-012: isolated focal trainer with compatible image inference

2026-10-28, accepted implementation choice under user's renewed autonomous optimization instruction. Keep all older frozen modules and artifacts byte-identical. New focal_loss.py wraps installed torchvision's binary sigmoid focal loss with validated parameters and FP32inputs. New train_focal.py derives the established image trainer into a new file; changes are explicit scope, focal loss and persisted loss/public-source guards, not silent changes to old defaults or workflows.

New trainer internal mode requires a nonempty train manifest and fresh public initialization; full mode must be explicit with fixed selectedepoch. Both modes reject supervised initialization, completed-run overwrite and exact-resume metadata mismatches. Selected/resume checkpoints persist loss specification and publicpretrainSHA; resumes verify gamma/alpha/scope/data/environment and all RNG/optimizer/scheduler/scaler state. Existing schema1 model/architecture/size remain valid for unchanged image inference; extra training metadata does not become an inference-time focal transform or calibration.

The only planned predictive treatment is a fixed focal objective at384, with the same training seed/geometry/augments/architecture as the BCE control. Keep class sampling, labels and downstream equal-probability/TTA policy fixed. AUC/AP gates, loss formula and fullselected epoch are frozen before relevant outcomes. Training/data/model/output paths are distinct v12 namespaces; no old-record migration, production dependency, platform submission or Gitpush.

Finite state transitions, measured preflight resources, source/model pins, independent validation and atomic staging reuse prior reviewed contracts. Stop this experiment on a failed resource/quality gate rather than retrying until a favorable result. Recover only after verified-dead owners and explicit checkpoint/config/RNG/data audit. Rollback remains using untouched existing submissions. OfficialT4 and99.3 remain unverified.
