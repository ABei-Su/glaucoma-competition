# ADR-003: Explicit backbone identity for stronger supervised candidates

Status: accepted under user's autonomous optimization request.

Extend model construction with an explicit supported architecture (resnet18/resnet50). Legacy calls/checkpoints default to resnet18. New training config and saved checkpoints record architecture; resume rejects architecture mismatch. Initialization checkpoints must match the selected architecture. Inference selects the architecture only from a trusted local checkpoint, never downloads weights and never adapts to test images.

Use official torchvision ResNet50 IMAGENET1K_V2, pretrained on ImageNet-1K. Archive the public weight, full SHA256, official model source/training recipe and BSD license separately from previous provenance. Existing v1/v2 packages are immutable.

Reuse the identical 384 lossless cache and data audit. Prior to fitting, run actual synthetic forward/backward capacity checks. Validate legacy inference and resume behavior in tests, plus a resnet50 checkpoint round-trip. Architecture is a persisted compatibility field, not a heuristic guessed from tensor shapes.
